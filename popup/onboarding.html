Before using Media Sniper

What Media Sniper processes locally for media detection and saving.

Media-related browser activity is observed

  • Page and media metadata are processed locally.
  • Authentication-related headers may be used briefly for confirmed media.
  • Sensitive headers are not persisted or replayed unchanged across origins.
  • Chromium may attach cookies for the target media site.

Nothing is sent to a Media Sniper server

  • Media processing runs in the browser.
  • There is no Media Sniper backend or telemetry.
  • Saving media contacts the site/CDN that serves it.

Storage and deletion

  • Settings and detected items use Chromium extension storage.
  • Clear removes detected items for the current tab.
  • Removing the extension removes extension-local data managed by Chromium.
